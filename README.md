# Voice Stand Up AI 🎤🤖

An AI-powered voice application that delivers personalized, interactive stand-up comedy routines and vocal entertainment. Combining a web-based frontend with a Python backend, this project creates a dynamic, real-time humor experience driven by artificial intelligence.

---

## 🚀 Features

* **Voice-Driven Interaction:** Speak to the AI and receive real-time, comedic responses.
* **Dynamic Stand-Up Generation:** Generates jokes, witty remarks, and crowd-work style humor based on user prompts or themes.
* **Responsive Web UI:** A sleek, user-friendly interface optimized for both desktop and mobile devices.
* **Audio Synthesis:** High-quality text-to-speech (TTS) playback to give the AI a distinct comedic personality and delivery timing.

---

## 🛠️ Built With

The project utilizes a modern full-stack architecture split across the following technologies:

* **Python (15.6%):** Powers the backend logic, AI integration, and natural language processing.
* **JavaScript (16.6%):** Handles frontend reactivity, web audio API controls, and asynchronous API calls.
* **HTML5 (18.1%) & CSS3 (49.7%):** Forms the structured, beautifully styled user interface and animations.
